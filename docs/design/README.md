# Original design documents

These documents describe CueBack's original multi-platform design: an Android app, a desktop companion (VS Code and browser collectors), device pairing, and a Go sync backend.

For the Shipaton 2026 release, the scope was narrowed to a **standalone Android app** with no backend. Every signal comes from the phone itself. See [ROADMAP.md](../ROADMAP.md) for the shipped scope.

They are kept for the product thinking and possible future work. Where they disagree with the code or with the documents one level up, the code and those documents are current.
